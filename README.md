# Counter_App_Pro

Counter Pro 🔢
A sleek, responsive web-based counter application designed with modern UI principles. Counter Pro allows users to increment or decrement values with dynamic step options (+1, +5, +10) and features real-time visual feedback through color-coded states.

Link:
[https://rosslergkboquiren.github.io/Counter_App_Pro/#]

✨ Features
Dynamic Increments: Switch between +1, +5, and +10 modes using a modern dropdown menu.

Visual States: The counter automatically changes color based on the value:

🟢 Green: 0 – 15

🟡 Yellow: 16 – 29

🔴 Red: 30+

Activity Log: Save your current count to a history log for later reference.

Responsive Design: Fully fluid layout that works perfectly on mobile, tablet, and desktop.

Safety Logic: Built-in protection to prevent negative counts.

🚀 How to Use
Open the index.html file in any modern web browser.

Select a Mode using the dropdown menu (default is +1).

Click Plus/Minus to adjust the count.

Click Save to record your progress in the Activity Log.

Click Reset to clear both the counter and the log.

🛠️ Built With
HTML5 - Semantic structure.

CSS3 - Custom properties (variables), Flexbox, and Glassmorphism styling.

JavaScript (ES6) - Dynamic DOM manipulation and state logic.
